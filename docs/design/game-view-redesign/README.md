# Game & tournament view redesign boards (approved 2026-10-21)

Design doc: docs/DES-MEETUP-ADDENDUM-game-view-redesign.md (v1.0 APPROVED). png for the look, html for exact sizes, spacing and colors. Sample names and counts are illustrative. The dashed orange notes on the boards are annotations, not UI.

- games-list: scope chips Mine | Public | All (Mine default) with the Active | All segmented switch in the same row (GV-1). Cards, sport chips, header unchanged.
- game-view: organizer game detail order — Details (venue row GV-2, invite-type row GV-3, organizer), Responses (GV-4), Invite (GV-5), Close game last (GV-7).
- invite-picker: multi-select picker, + stages / − unstages, grouped Selected / Available / Already in this game, one Send (GV-5).
- popups: venue sheet (GV-2), Invited sheet (GV-3), combined user pop-up with no View Details step (GV-6).
- tournament-view: same order with committee row, Responses grouped Registered / Accepted-not-registered / Declined / Pending, Fixtures section, Close tournament last (GV-4, GV-7, AD-10).
